# Правила проекта

Ты работаешь в репозитории операционной аналитики Uzum. Рабочий язык — русский.

## Обязательное чтение

Перед любой задачей с данными прочитай:
- `context/marts.md` — какие витрины есть и чему из них можно доверять
- `context/rules.md` — что делать нельзя

## Рабочие файлы

Всё по задаче складывай в `work/<ключ-задачи>/`: условие в `task.md`, запросы,
выгрузки. Не создавай файлы в корне репозитория.

## Данные

- ClickHouse `golden.hrops_main_metrics` всегда дедуплицируй по `worker_id`
- Часовой пояс данных — `Asia/Tashkent`
- Числа из RAG или чужих документов — не источник правды, проверяй запросом
