# Требования сертификации по уровням

## Уровень 1: Стабильность и визуализация

| Требование | Как проверить |
|---|---|
| Все чарты грузятся без ошибок | error rate < 7% за 7 дней на обзорном дашборде Superset |
| Загрузка чарта ≤ 10 сек | время загрузки на обзорном дашборде |
| Чарты работают после применения фильтра | проверить фильтры вручную |
| Все фильтры грузятся корректно | проверить панель фильтров |
| Верно настроен scope фильтра | проверить, что фильтр применяется к нужным чартам |
| Метрики созданы на уровне датасета | проверить конфиг чарта — Metrics vs ad-hoc SQL |
| Есть краткое описание или ссылка на документацию | поле описания дашборда |
| Заданы обязательные теги (cat:, team:, crit:) | теги дашборда |
| Владелец указан в OpenMetadata | каталог OMD |
| Настроены роли доступа | роли дашборда |
| Используется брендовая палитра | цветовая схема дашборда |
| Названия чартов информативны, один язык | заголовки чартов |
| Денежные метрики используют динамический курс | формулы метрик |
| Настроен часовой пояс UTC+5 | настройки данных |

## Уровень 2: Документация и глоссарий (для Tier 1–2)

| Требование | Как проверить |
|---|---|
| Указан домен в OMD | OpenMetadata |
| Указана техническая команда-владелец в OMD | поле Owners |
| Указан Tier в OMD | тег критичности |
| Указан бизнес-владелец | метаданные OMD |
| Есть краткое описание в OMD | поле description |
| Есть ссылка на задачу Jira по разработке | метаданные OMD |
| Указана частота обновления данных | метаданные |
| Указано время обновления (UTC+5) | метаданные |
| Есть ссылки на источники данных и пайплайны | lineage или метаданные |
| Есть ссылка на Confluence (если нужна доп. документация) | метаданные |
| Метрики описаны в разделе Metrics в OMD | каталог метрик |
| Минимум 3 DQ-теста на витрину | dbt-тесты |

## Уровень 3: Высокое качество ETL (для Tier 1)

| Требование | Как проверить |
|---|---|
| Данные строятся через dbt/агрегированные витрины | источники запросов |
| Нет JOIN, критично влияющих на производительность | ревью SQL-запросов |
| Настроены алерты на падение пайплайна | алерты в оркестраторе пайплайнов |

# Уровни критичности

| Tier | Описание | Цель сертификации |
|---|---|---|
| **Tier 1** | Отчётность для C-level, аудит, инвесторы, KPI | Уровень 3 |
| **Tier 2** | Решения среднего менеджмента, KPI департамента | Уровень 2 |
| **Tier 3** | Локальные командные дашборды | Уровень 1 |
| **Tier 4** | Личные, разовые, тестовые | Без сертификации |
