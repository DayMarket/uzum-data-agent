# Инструменты и справочные ссылки

## Справочные ссылки

- Правила публикации, требования сертификации, процесс сертификации, уровни
  критичности, гайд по тегам, цветовые палитры — см. корпоративную базу знаний
  Confluence (`confluence.uzum.com`), раздел по сертификации дашбордов.
- Обзорный дашборд Superset: https://bi.uzum.uz/superset/dashboard/superset_overview/

## Доступные инструменты

| Инструмент | Назначение | Коннектор |
|---|---|---|
| `mcp__superset__get_dashboard` | Свойства дашборда + чарты | superset |
| `mcp__superset__get_dashboard_screenshot` | Рендер PNG (визуальная проверка) | superset |
| `mcp__superset__update_dashboard` | Задать сертификацию / json_metadata | superset |
| Создание/чтение страниц | Документация дашборда | atlassian |
| Поиск сущностей / обновление | Владелец, домен, теги, lineage | openmetadata |
