# Разбор проблем с доступом

1. Посмотри текст ошибки и определи, какой коннектор её дал.
2. Проверь, включён ли он: `.claude/settings.local.json`, список
   `enabledMcpjsonServers`.
3. Проверь, есть ли переменная в `~/.config/uzum-ai/secrets.env` (значения не
   показывай человеку и не выводи в ответ — только факт наличия).
4. Разбери по типовым причинам:
   - **все прод-источники недоступны** → Netbird не запущен;
   - **коннекторы «ожидают одобрения»** → не принят диалог доверия к папке,
     перезапусти сессию и ответь «да»;
   - **401 или 403 у Jira, Grafana, OpenMetadata** → истёк токен, перевыпустить
     по инструкции в `connectors/ACCESS.md`;
   - **Superset или Trino просит логин** → истекла SSO-сессия, откроется браузер;
   - **ClickHouse отвергает пароль** → пароль меняется заявкой в JSM.
5. Дай человеку ровно один следующий шаг, а не список из пяти.
6. Если доступа не хватает совсем — подскажи команду `./setup.sh --add <сервер>`.
