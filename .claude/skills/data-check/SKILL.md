# Сверка расхождений

1. Зафиксируй, что именно сверяем: какие две цифры, метрика, период, разрез.
   Если что-то из этого не указано в задаче — спроси у человека, не угадывай:
   додуманный период или разрез даёт уверенный, но неверный вывод о причине
   расхождения. Итог запиши в `work/<ключ>/task.md`.
2. Прежде чем запрашивать, сверь обе витрины (или дашборды) с реестрами
   `context/marts.md` и `context/dashboards.md`. Любая из сторон помечена
   «🚫 запрещено — правило 1» — останавливаешься сразу, дальше не запрашиваешь
   ни одну из двух цифр, сообщаешь человеку (правило 1, `CLAUDE.md`).
3. Достань обе цифры независимыми запросами. Не выводи одну из другой.
4. Сузь расхождение по одному измерению за раз: сначала по датам, потом по
   складам, потом по статусам. Так находится место, а не общее «не сходится».
5. Типовые причины, проверь их первыми: разные часовые пояса, дубли после
   джойна, разные фильтры по отменённым заказам, витрина не долилась.
6. **Обязательно прогони скилл `data-sanity`.**
7. Ответ человеку: где именно расходится, на сколько, почему, что чинить.
