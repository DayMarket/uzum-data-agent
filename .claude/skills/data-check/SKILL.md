# Сверка расхождений

1. Зафиксируй, что именно сверяем: метрика, период, разрез. Запиши в
   `work/<ключ>/task.md`.
2. Достань обе цифры независимыми запросами. Не выводи одну из другой.
3. Сузь расхождение по одному измерению за раз: сначала по датам, потом по
   складам, потом по статусам. Так находится место, а не общее «не сходится».
4. Типовые причины, проверь их первыми: разные часовые пояса, дубли после
   джойна, разные фильтры по отменённым заказам, витрина не долилась.
5. **Обязательно прогони скилл `data-sanity`.**
6. Ответ человеку: где именно расходится, на сколько, почему, что чинить.
