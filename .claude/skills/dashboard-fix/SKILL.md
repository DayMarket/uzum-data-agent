# Починка дашборда

1. Открой дашборд через коннектор `superset`, найди падающий чарт и посмотри
   его запрос.
2. Уточни у человека, если неясно: какой именно чарт считается сломанным, в
   чём это выражается (не грузится, показывает не то, старые данные), и какой
   результат нужен — готовый запрос или применённая правка дашборда. Не
   угадывай — правка не по адресу хуже её отсутствия.
3. Воспроизведи запрос напрямую в ClickHouse — так видно настоящую ошибку, а не
   обёртку Superset.
4. Частые причины: переименовали колонку в витрине, поменялся тип, витрина
   переехала, фильтр по несуществующему значению.
5. Почини запрос и проверь на тех же фильтрах, что стоят в дашборде по умолчанию.
6. **Обязательно прогони скилл `data-sanity`** — числа после починки должны
   сойтись с соседним периодом.
7. Правь дашборд только если задача явно об этом просит. Иначе покажи человеку
   готовый запрос и предложи применить.
