# Починка дашборда

1. Открой дашборд через коннектор `superset`, найди падающий чарт и посмотри
   его запрос.
2. Воспроизведи запрос напрямую в ClickHouse — так видно настоящую ошибку, а не
   обёртку Superset.
3. Частые причины: переименовали колонку в витрине, поменялся тип, витрина
   переехала, фильтр по несуществующему значению.
4. Почини запрос и проверь на тех же фильтрах, что стоят в дашборде по умолчанию.
5. **Обязательно прогони скилл `data-sanity`** — числа после починки должны
   сойтись с соседним периодом.
6. Правь дашборд только если задача явно об этом просит. Иначе покажи человеку
   готовый запрос и предложи применить.
