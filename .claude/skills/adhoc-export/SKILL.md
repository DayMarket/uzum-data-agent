# Разовая выгрузка

1. Прочитай `context/marts.md` и выбери витрину. Не изобретай джойны по сырым
   таблицам, если есть готовая витрина.
2. Уточни у человека, если непонятны: период, гранулярность, фильтры по складам
   или категориям. Не угадывай — плохая выгрузка хуже её отсутствия.
3. Напиши SQL, начни с `LIMIT 100` и покажи структуру результата.
4. После подтверждения сними полную выгрузку в `work/<ключ>/result.csv`.
5. **Обязательно прогони скилл `data-sanity`.**
6. Отдай человеку: краткий вывод словами, путь к файлу, использованные витрины.

Запрос сохраняй в `work/<ключ>/query.sql` — он понадобится при повторе задачи.
