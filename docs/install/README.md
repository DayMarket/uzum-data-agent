# Установка — подробно, по шагам

В README установка описана коротко: для того, кто ставит такое не в первый
раз, этого хватает. Здесь то же самое, но по шагам и с проверкой после
каждого — что должно появиться на экране, чтобы можно было идти дальше.

- **macOS** → [macos.md](macos.md)
- **Windows** → [windows.md](windows.md) (установка идёт внутри WSL2, и
  других поддержанных путей нет — почему, объяснено там же)

Короткая версия и список коннекторов живут в
[README репозитория](../../README.md); где взять каждый доступ —
[connectors/ACCESS.md](../../connectors/ACCESS.md). Здесь это не
продублировано намеренно: два списка коннекторов разошлись бы через месяц.

## Что одинаково на обеих системах

Разница между macOS и Windows — только в том, как довести машину до
рабочего состояния. Дальше начинается общая часть, и она везде одна.

**Устанавливает всё один мастер — `./setup.sh`.** Он спрашивает доступы по
одному и проверяет каждый **живым запросом**: не «принял значение», а
«сходил и увидел 47 баз», «увидел тебя как Denis Platon». Это и есть смысл
мастера — показать, что доступ реально работает, а не что его аккуратно
записали.

**Двух обязательных доступов достаточно, чтобы начать.** ClickHouse WMS
(данные склада) и Jira — без них инструмент не делает того, ради чего его
ставят. Остальные семь коннекторов добавляются потом одной командой
`./setup.sh --add <коннектор>`, полный мастер перезапускать не нужно.

**Повторный запуск не начинает с нуля.** Всё, что уже записано в
`~/.config/uzum-ai/secrets.env`, подставляется само и заново не
спрашивается — но проверяется живым запросом всё равно. Так что запустить
`./setup.sh` ещё раз всегда безопасно.

**Прод-данные видны только через Netbird.** ClickHouse, Trino, Grafana и
OpenMetadata живут в корпоративной сети. Без поднятого туннеля мастер
честно скажет, что их не видит, и это не поломка установки.

**Запускать сессию нужно командой `uzum`, а не голым `codex` или
`claude`.** `uzum` подгружает секреты в окружение и подключает профиль
разрешений; без него коннекторы не увидят кредов, а у Codex ещё и не
применится запрет на чтение `.env` и `~/.ssh` — при этом сессия будет
выглядеть совершенно рабочей. Подробности — «Ограничения Codex» в README.

## Сломалось прямо во время установки

- Мастер сам называет причину и команду для повтора — читай его вывод, там
  не «ошибка», а что именно не ответило.
- Уже в сессии: `$fix-access` (Codex) или `/fix-access` (Claude Code).
- Не помогло — Настя Бир.
