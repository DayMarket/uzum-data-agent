# Шаблоны отчётов

## Отчёт о сертификации дашборда

Структура:
```markdown
# Отчёт о сертификации дашборда: [Название]
URL: [dashboard_url]
Дата: [дата]

## Текущий статус
- Требования публикации: [PASS/FAIL]
- Сертификация уровень 1: [PASS/FAIL/N/A]
- Сертификация уровень 2: [PASS/FAIL/N/A]
- Сертификация уровень 3: [PASS/FAIL/N/A]

## Найденные проблемы

### Критичные проблемы (блокируют публикацию)
1. [Описание проблемы]
   - Сейчас: [текущее состояние]
   - Нужно: [ожидаемое состояние]
   - Как починить: [пошагово]

### Проблемы сертификации (уровень 1)
...

### Проблемы сертификации (уровень 2)
...

## Рекомендуемые действия
1. [Действие с оценкой трудоёмкости]
...
```

## Итоговый отчёт

**После выполнения всех подтверждённых фиксов ВСЕГДА дай сводку в этом формате:**

```markdown
# ✅ Проверка сертификации завершена

## Дашборд: [Название]
URL: [url]

## Сводка
- Найдено проблем: X
- Починено: Y
- Пропущено (не подтверждено): Z

## Внесённые изменения (было → стало)

### 1. [Категория изменения]
| Параметр | Было | Стало |
|---|---|---|
| Название дашборда | "Marketing Overview" | "Market: Marketing Overview" |
| Теги | `cat:marketing` | `cat:marketing`, `team:marketing`, `crit:Tier2` |
| Роли | (нет) | Market Team Data, Market Viewer |
| Страница Confluence | (нет) | [Создана: ссылка] |

### 2. [Следующее изменение]
| Параметр | Было | Стало |
|---|---|---|
| ... | ... | ... |

## Не починено (человек отказался)
- [Проблема 1]: [причина]

## Осталось (нужны ручные действия)
- [Проблема, которую нельзя автоматизировать]

## Текущий статус сертификации
- Требования публикации: ✅ PASS / ❌ FAIL
- Уровень 1: ✅ PASS / ❌ FAIL / ⏳ Частично
- Уровень 2: ✅ PASS / ❌ FAIL / ⏳ Частично
- Уровень 3: ✅ PASS / ❌ FAIL / ⏳ Частично

## Дальше
1. [Рекомендуемое действие, если проблемы остались]
2. ...
```

**КРИТИЧНО: для каждого внесённого изменения всегда указывай таблицу было → стало.
Это обязательно для прозрачности и аудита.**
